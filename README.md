# Product

Point d'entrée de l'équipe pour le Givaudan AI Innovation Challenge.

- **Tickets** : toutes les issues se créent ici. Pour travailler sur une issue, ouvrez une branche depuis l'issue (bloc « Development ») dans le dépôt concerné : [`app`](https://github.com/yaourt-hackathon/hackathon-app) ou [`data`](https://github.com/yaourt-hackathon/data).
- **Documentation** : le sujet, les décisions transverses et les notes produit vivent ici. Les ADR techniques restent dans le dépôt qu'ils concernent.
